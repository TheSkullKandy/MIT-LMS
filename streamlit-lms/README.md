# MIT LMS (Streamlit Version)

## How to Run

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Start the app:
   ```
   streamlit run app.py
   ```

3. Visit the local URL provided in your terminal.

## Deployment

- Push this folder to a GitHub repository.
- Go to [Streamlit Community Cloud](https://streamlit.io/cloud) and deploy your app by connecting your repo.
