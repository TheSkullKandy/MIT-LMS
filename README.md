# Modern Streamlit LMS

A visually unified, modern Learning Management System (LMS) built with **Streamlit**. This project features a beautiful, consistent UI/UX, interactive dashboards, and comprehensive management for students, assignments, courses, calendar events, and virtual classes.

## 🚀 Features
- **Custom CSS** for a beautiful, consistent UI/UX (gradient headers, glassmorphism, responsive cards, and more)
- **Interactive dashboards** and analytics powered by **Plotly** (Power BI-style visualizations)
- **Student, assignment, course, calendar, and virtual class management** with real-time filtering and status indicators
- **Role-based views** for students and instructors
- **Responsive design** for all devices
- **Accessible, high-contrast layouts** for usability
- **No overlays or faded text**—all content is crisp and clear

## 🛠️ Tech Stack
- [x] Streamlit (Python)
- [x] Plotly (for interactive charts)
- [x] Custom CSS
- [x] Responsive HTML/CSS components

## 📦 Setup & Usage

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd LMS_Project
   ```
2. **(Optional) Create a virtual environment:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```
3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the app:**
   ```bash
   streamlit run streamlit-lms/app.py
   ```
5. **Open in your browser:**
   - Local: [http://localhost:8504](http://localhost:8504)
   - Network: [http://<your-ip>:8504](http://<your-ip>:8504)
